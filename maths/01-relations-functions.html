1. Types of relations

Q. Define reflexive, symmetric, transitive and equivalence relations.1–2 M

TypeCondition (R on A)
Reflexive(a, a) ∈ R for every a ∈ A
Symmetric(a, b) ∈ R ⇒ (b, a) ∈ R
Transitive(a, b), (b, c) ∈ R ⇒ (a, c) ∈ R
Equivalenceall three

Example: A = {1, 2, 3}, R = {(1,1), (2,2), (1,2), (2,1)}: not reflexive ((3,3) missing), symmetric, transitive → symmetric and transitive but not reflexive.

R = {(x, y) : y divisible by x} on {1,…,6}: reflexive, transitive, not symmetric.

Number of relations on a set with n elements = 2^{n²}. Number of functions from A (m elements) to B (n elements) = nᵐ; e.g. A = {M, S}, B = {1..6}: 6² = 36. Bijections on a 5-element set: 5! = 120.

2. Equivalence relation proofs

Q. Show that R = {(a, b) : |a − b| is a multiple of 4} on A = {x ∈ Z : 0 ≤ x ≤ 12} is an equivalence relation. Find [1] and [3].5 M · repeated

Reflexive: |a − a| = 0 = 4 × 0 ✓.

Symmetric: |a − b| = 4k ⇒ |b − a| = |a − b| = 4k ✓.

Transitive: a − b = ±4k, b − c = ±4m ⇒ a − c = (a − b) + (b − c) = 4(±k ± m), a multiple of 4 ✓.

Hence R is an equivalence relation.

[1] = {1, 5, 9}; [3] = {3, 7, 11}; [0] = {0, 4, 8, 12}.

Q. Show that (a, b) R (c, d) ⇔ a + d = b + c on N × N is an equivalence relation.5 M

Reflexive: a + b = b + a ✓. Symmetric: a + d = b + c ⇒ c + b = d + a ✓.

Transitive: a + d = b + c and c + f = d + e. Adding: a + d + c + f = b + c + d + e ⇒ a + f = b + e ⇒ (a, b) R (e, f) ✓.

Same steps work for a² + d² = b² + c².

Q. L = set of lines in a plane, R = {(L₁, L₂) : L₁ ∥ L₂}. Show R is an equivalence relation and find lines related to y = 2x + 4.5 M

A line is parallel to itself (reflexive); L₁ ∥ L₂ ⇒ L₂ ∥ L₁ (symmetric); L₁ ∥ L₂, L₂ ∥ L₃ ⇒ L₁ ∥ L₃ (transitive). Lines related to y = 2x + 4: all lines y = 2x + c, c ∈ R.

Similarly, "|a − b| is even" on Z and "2 divides (a − b)" are equivalence relations with two classes: evens and odds.

3. One-one, onto, bijective

Q. How do you test one-one and onto?method

  • One-one (injective): f(x₁) = f(x₂) ⇒ x₁ = x₂. Graph: every horizontal line cuts at most once.
  • Onto (surjective): for every y in the codomain, solve y = f(x) and check x lies in the domain. Range = codomain.
  • Bijective = both ⇒ invertible.

f(x) = x² + 1 on R → R: f(1) = f(−1) (not one-one); 0 has no pre-image (not onto) → neither.

f(x) = (3x + 2)/5 → f⁻¹(x) = (5x − 2)/3.

Q. Show that f : R − {−4/3} → R − {4/3}, f(x) = (4x + 3)/(3x + 4) is bijective. Find x with f(x) = 2.5 M · repeated

One-one: (4x₁ + 3)(3x₂ + 4) = (4x₂ + 3)(3x₁ + 4) ⇒ 12x₁x₂ + 16x₁ + 9x₂ + 12 = 12x₁x₂ + 16x₂ + 9x₁ + 12 ⇒ 7x₁ = 7x₂ ⇒ x₁ = x₂ ✓.

Onto: y = (4x + 3)/(3x + 4) ⇒ x = (3 − 4y)/(3y − 4), which exists for every y ≠ 4/3. Also x ≠ −4/3, because (3 − 4y)/(3y − 4) = −4/3 would give 9 = 16. So every y in the codomain has a pre-image ✓.

f(x) = 2 ⇒ 4x + 3 = 6x + 8 ⇒ x = −5/2.

Q. Show f(x) = 2x/(1 + x²), R → R, is neither one-one nor onto. Find A so that f : R → A is onto.5 M

f(2) = 4/5 = f(1/2) → not one-one. y = 2x/(1 + x²) ⇒ yx² − 2x + y = 0; real x needs 4 − 4y² ≥ 0 ⇒ −1 ≤ y ≤ 1, so e.g. 2 has no pre-image → not onto. Range = [−1, 1] → take A = [−1, 1].

f(x) = 4x² + 4x − 5 on [0, ∞) → [−5, ∞): increasing on x ≥ 0 (one-one), y = (2x + 1)² − 6 covers [−5, ∞) (onto). f(p) = 3 ⇒ (2p + 1)² = 9 ⇒ p = 1.

Q. Evaluate the principal values.1–2 M

  • sin⁻¹(sin 2π/3) = sin⁻¹(sin π/3) = π/3.
  • sin⁻¹(sin 3π/5) = π − 3π/5 = 2π/5.
  • cos⁻¹(cos 7π/6) = cos⁻¹(cos 5π/6) = 5π/6 (2π − 7π/6).
  • cos⁻¹(cos 4π/3) = 2π − 4π/3 = 2π/3.
  • cot⁻¹(−1/√3) = π − π/3 = 2π/3.
  • sin⁻¹(−1/2) + 2cos⁻¹(−1/2) + tan⁻¹(1) = −π/6 + 4π/3 + π/4 = 17π/12.
  • tan⁻¹[2 sin(2 cos⁻¹(√3/2))] = tan⁻¹[2 sin(π/3)] = tan⁻¹√3 = π/3.
  • sin(2 tan⁻¹(2/3)) = 2(2/3)/(1 + 4/9) = 12/13.
  • Range of 2 sin⁻¹(x/2) + π/2: [−π/2, 3π/2].
  • tan⁻¹x > cot⁻¹x when x > 1.

5. ITF simplification

Q. Write tan⁻¹[(√(1 + x²) − 1)/x], x ≠ 0, in simplest form.2–3 M · repeated

Put x = tan θ: √(1 + tan²θ) = sec θ. Expression = tan⁻¹[(sec θ − 1)/tan θ] = tan⁻¹[(1 − cos θ)/sin θ] = tan⁻¹[tan(θ/2)] = θ/2 = ½ tan⁻¹x.

tan⁻¹√((1 − x)/(1 + x)): put x = cos θ → tan⁻¹(tan θ/2) = ½ cos⁻¹x.

Solve tan⁻¹2x + tan⁻¹3x = π/4: (5x)/(1 − 6x²) = 1 ⇒ 6x² + 5x − 1 = 0 ⇒ x = 1/6 (x = −1 rejected since LHS would be negative).

Substitutions: √(a² − x²) → x = a sin θ; √(a² + x²) → x = a tan θ; (1 − x²)/(1 + x²) → x = tan θ; √((1 − x)/(1 + x)) → x = cos θ.

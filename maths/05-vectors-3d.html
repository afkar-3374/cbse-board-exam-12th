1. Dot product, angle, projection

Q. Formulae for angle, projection and perpendicularity.1–2 M

a⃗·b⃗ = |a||b| cos θ = a₁b₁ + a₂b₂ + a₃b₃  |  projection of a⃗ on b⃗ = (a⃗·b⃗)/|b⃗|
  • |a| = √3, |b| = 2, a·b = √6 ⇒ cos θ = √6/(2√3) = 1/√2 ⇒ θ = π/4.
  • Projection of i + 2j + 3k on 2i + j + 2k = (2 + 2 + 6)/3 = 10/3.
  • Projection of 2i − j + k on i + 2j − 2k = (2 − 2 − 2)/3 = −2/3.
  • 2i + λj + k ⟂ i − 2j + 3k ⇒ 2 − 2λ + 3 = 0 ⇒ λ = 5/2.
  • |a − b|² = |a|² + |b|² − 2a·b: |a| = 3, |b| = 4, a·b = 6 ⇒ |a − b| = √13.
  • |a| = |b| = |a + b| = 1 ⇒ a·b = −½ ⇒ |a − b| = √3.
  • a + b + c = 0, all unit ⇒ a·b + b·c + c·a = −3/2.
  • √3 a − b unit (a, b unit) ⇒ 3 + 1 − 2√3 cos θ = 1 ⇒ cos θ = √3/2 ⇒ θ = 30°.

2. Cross product & area

Q. Find a unit vector perpendicular to a = 2i − j + k and b = i + j − 2k.2 M · repeated

a × b = |i j k; 2 −1 1; 1 1 −2| = i(2 − 1) − j(−4 − 1) + k(2 + 1) = i + 5j + 3k; |a × b| = √35.

n̂ = ±(i + 5j + 3k)/√35

Vector ⟂ to i + j and i − j: (i + j) × (i − j) = −2k → any multiple of k, e.g. 3k.

|a × b| = |a||b| sin θ: |a| = 3, |b| = √2/3, unit ⇒ sin θ = 1/√2 ⇒ θ = π/4. |a × b| = |a·b| ⇒ tan θ = 1 ⇒ θ = π/4.

|a| = 3, |b| = 4, |a × b| = 6 ⇒ sin θ = ½ ⇒ a·b = 12 cos θ = ±6√3.

Q. Area of a triangle and parallelogram using vectors.2–3 M

Parallelogram (sides a, b) = |a × b|; (diagonals d₁, d₂) = ½|d₁ × d₂|; triangle ABC = ½|AB × AC|

A(2, 3, 1), B(4, 1, 3), C(−1, 2, 0): AB = 2i − 2j + 2k, AC = −3i − j − k. AB × AC = i(2 + 2) − j(−2 + 6) + k(−2 − 6) = 4i − 4j − 8k. Area = ½√96 = 2√6 sq units.

Unit vector along the diagonal of a parallelogram with sides 2i − 4j + 5k and i − 2j − 3k: d = 3i − 6j + 2k, |d| = 7 ⇒ (3i − 6j + 2k)/7.

3. Lines: equations, direction cosines, angle

Q. Vector and Cartesian equations of a line; direction cosines.1–2 M

r⃗ = a⃗ + λb⃗  ⇔  (x − x₁)/a = (y − y₁)/b = (z − z₁)/c
  • DCs: l = a/√(a² + b² + c²) etc., with l² + m² + n² = 1. So (½, ½, ½) cannot be DCs.
  • (x − 1)/2 = (1 − y)/3 = (z − 2)/6 → rewrite (y − 1)/(−3) → DRs 2, −3, 6 → DCs 2/7, −3/7, 6/7.
  • Flight path r = (2i − j + 3k) + λ(3i + 4j + 12k): DCs 3/13, 4/13, 12/13; λ from 0 to 2 covers 2 × 13 = 26 km.
  • Line makes 60° with y- and z-axes: cos²α + ¼ + ¼ = 1 ⇒ α = 45°. sin²α + sin²β + sin²γ = 2.
  • Missile x = 3t, y = −4t, z = t: distance at t = 5 = 5√26 km.

Q. Angle between two lines; condition for perpendicular / parallel.1–3 M

cos θ = |a₁a₂ + b₁b₂ + c₁c₂| / (√(a₁² + b₁² + c₁²) √(a₂² + b₂² + c₂²))
  • Pipes along (i + j) and (j + k): cos θ = 1/(√2·√2) = ½ ⇒ θ = 60°.
  • (2, 2, 1) and (4, 1, 8): cos θ = (8 + 2 + 8)/(3 × 9) = 2/3.
  • Lines (2, 5, 4) and (1, 2, −3): 2 + 10 − 12 = 0 ⇒ 90°. (A–R: reason "skew lines are parallel and intersecting" is false.)
  • (1 − x)/3 = (7y − 14)/(2λ) = (5z − 10)/11 and (7 − 7x)/(3λ) = (y − 5)/1 = (6 − z)/5 perpendicular: DRs (−3, 2λ/7, 11/5) and (−3λ/7, 1, −5) ⇒ 9λ/7 + 2λ/7 − 11 = 0 ⇒ λ = 7.
  • Parallel: DRs proportional, e.g. (−2, μ, −1) ∥ (−μ, 2, 1)… solve the ratio.

4. Foot of perpendicular & image

Q. Find the foot of the perpendicular from P(4, 2, 2) to the line (x − 1)/2 = (y + 1)/1 = (z − 2)/2, the length, and the image of P.3–5 M · case study

Step 1: general point Q = (2λ + 1, λ − 1, 2λ + 2).

Step 2: PQ = (2λ − 3, λ − 3, 2λ). PQ ⟂ line: 2(2λ − 3) + (λ − 3) + 2(2λ) = 0 ⇒ 9λ − 9 = 0 ⇒ λ = 1.

Step 3: foot Q = (3, 0, 4); length PQ = √(1 + 4 + 4) = 3 units (= 30 m if 1 unit = 10 m).

Step 4: image P′ = 2Q − P = (2, −2, 6).

Also asked: A(−1, 8, 4) to line BC through B(0, −1, 3), C(2, −3, −1): line (x)/2 = (y + 1)/(−2) = (z − 3)/(−4); foot (−2, 1, 7), image (−3, −6, 10).

Points on a line at a given distance: write the general point, set distance² = d², solve the quadratic in λ.

5. Shortest distance

Q. Find the shortest distance between r = (i + 2j + k) + λ(i − j + k) and r = (2i − j − k) + μ(2i + j + 2k).3–5 M · repeated

Skew: d = |(a₂ − a₁)·(b₁ × b₂)| / |b₁ × b₂|
Parallel (b): d = |b × (a₂ − a₁)| / |b|

a₂ − a₁ = i − 3j − 2k. b₁ × b₂ = |i j k; 1 −1 1; 2 1 2| = i(−2 − 1) − j(2 − 2) + k(1 + 2) = −3i + 0j + 3k, |·| = 3√2.

d = |(1)(−3) + 0 + (−2)(3)|/(3√2) = 9/(3√2) = 3/√2 units.

Parallel lines r = (i + j) + λ(i + 2j + 2k), r = (4i + j) + μ(i + 2j + 2k): a₂ − a₁ = 3i; b × (3i) = |i j k; 1 2 2; 3 0 0| = 0i + 6j − 6k, |·| = 6√2; |b| = 3 ⇒ d = 2√2.

Drone paths (x − 1)/2 = y/1 = (z − 2)/2 and (x − 2)/1 = (y − 4)/2 = (z − 2)/(−2): angle cos θ = |2 + 2 − 4|/9 = 0 ⇒ 90°. b₁ × b₂ = (−6, 6, 3), |·| = 9; a₂ − a₁ = (1, 4, 0) ⇒ d = |−6 + 24|/9 = 2 km ≥ 1.5 km ⇒ safety rule satisfied.

Intersecting lines give d = 0; to find the point of intersection equate the general points.

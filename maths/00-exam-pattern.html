Repeated question types

  • Equivalence relation on A = {0,…,12}, |a − b| multiple of 4 — find the class [1] = {1, 5, 9} (several papers).
  • (a, b) R (c, d) ⇔ a + d = b + c or a² + d² = b² + c² on N × N — equivalence proof.
  • f(x) = (4x + 3)/(3x + 4) bijective, or x²+1 / 2x/(1+x²) neither one-one nor onto.
  • ∫₀^{π/4} log(1 + tan x) dx = (π/8) log 2 and ∫₀^{π/2} log(tan x) dx = 0.
  • Area between y² = 4ax and a line, circle and line (pizza/knife case), x² + y² = 8 with y² = 2x.
  • Use AB = kI to find A⁻¹ and solve the system (product of two given 3×3 matrices).
  • A² − 5A + 7I = O ⇒ A⁻¹ = (5I − A)/7.
  • Open box from a square sheet (cut squares x from corners) → max volume; box with square base and fixed volume → min cost / surface.
  • Foot of perpendicular and image of a point in a line; shortest distance between skew lines and between parallel lines.
  • Corner-point LPP with max at two points ⇒ infinitely many optimal solutions; unbounded region needs the open half-plane check.

A–R and MCQ traps

  • sin⁻¹(sin 2π/3) = π/3 (not 2π/3); cos⁻¹(cos 7π/6) = 5π/6; cos⁻¹(cos 4π/3) = 2π/3.
  • Direction cosines (1/2, 1/2, 1/2) are impossible since l² + m² + n² ≠ 1.
  • |adj A| = |A|^{n−1}; |kA| = kⁿ|A|; |A⁻¹| = 1/|A|.
  • Degree is defined only if the DE is a polynomial in derivatives.
  • |x − 3| is continuous but not differentiable at 3.
  • ∫₋ₐ^a odd function = 0, so ∫₋₂² (x⁵ + x³ + 1) dx = 4.

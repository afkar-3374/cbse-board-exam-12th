1. Types, operations, transpose

Q. Construct a 2 × 2 matrix with aij = (i + 2j)²/2.2 M

a₁₁ = 9/2, a₁₂ = 25/2, a₂₁ = 16/2 = 8, a₂₂ = 36/2 = 18 → A = [[9/2, 25/2], [8, 18]].

Q. Define symmetric and skew-symmetric matrices. Express any square matrix as their sum.2–3 M

Symmetric: A′ = A. Skew-symmetric: A′ = −A (so all diagonal elements are 0).

A = ½(A + A′) + ½(A − A′)

First part is symmetric, second is skew-symmetric.

Example: [[0, a, 3], [2, b, −1], [c, 1, 0]] skew-symmetric ⇒ a = −2, b = 0, c = −3 ⇒ a + b + c = −5.

Q. When is AB defined? Find A²⁰²⁵ for A = [[0, 1], [−1, 0]].1 M

Am×nBp×q is defined iff n = p; result is m × q. A (2×3) and B (3×2): both AB and BA defined.

A² = −I ⇒ A⁴ = I ⇒ A²⁰²⁵ = A^{4·506 + 1} = A.

[[−a, b], [c, a]]² = I ⇒ a² + bc = 1 ⇒ 1 − a² − bc = 0.

2. Determinant properties & area

Q. Key determinant results for a square matrix A of order n.1 M · every paper

|kA| = kⁿ|A|  |  |AB| = |A||B|  |  |A′| = |A|  |  |A⁻¹| = 1/|A|  |  |adj A| = |A|ⁿ⁻¹
  • n = 3, |A| = 4: |adj A| = 16, |2A| = 32, |(3A)⁻¹| = 1/(27|A|).
  • |A| = −1, |B| = 3, order 3: |2AB| = 8(−3) = −24.
  • Order 2, |P| = 2, |Q| = 3: |adj(PQ)| = |PQ| = 6.
  • |A′| = 5, order 3: |5A⁻¹| = 125/5 = 25.
  • |A³| = 27 for [[x, 2], [2, x]] ⇒ |A| = 3 ⇒ x² − 4 = 3 ⇒ x = ±√7.
  • Sum of products of elements of one row with cofactors of another row = 0.

Q. Find the area of a triangle using determinants; find k or the equation of a line.2–3 M

Area = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|

P(3, 1), Q(9, 3), R(5, 7): ½|3(−4) + 9(6) + 5(−2)| = ½|−12 + 54 − 10| = 16 sq units.

Equation of PQ: |x y 1; 3 1 1; 9 3 1| = 0 ⇒ x(1 − 3) − y(3 − 9) + (9 − 9) = 0 ⇒ x − 3y = 0.

(−3, 0), (3, 0), (0, k) with area 9: ½ × 6 × |k| = 9 ⇒ k = ±3. Collinear points: area = 0.

3. Adjoint & inverse

Q. Define adjoint and write the formula for A⁻¹. When does A⁻¹ exist?1–2 M

adj A = transpose of the cofactor matrix. A(adj A) = (adj A)A = |A| I.

A⁻¹ = adj A / |A|   (exists iff |A| ≠ 0, i.e. A is non-singular)

For 2 × 2: A = [[a, b], [c, d]] ⇒ adj A = [[d, −b], [−c, a]].

(AB)⁻¹ = B⁻¹A⁻¹, (A′)⁻¹ = (A⁻¹)′.

Example: [[1, 1, −2], [λ, 1, −3], [5, 4, −9]]: |A| = 1(−9 + 12) − 1(−9λ + 15) − 2(4λ − 5) = 3 + 9λ − 15 − 8λ + 10 = λ − 2 → A⁻¹ exists iff λ ≠ 2.

4. A² − kA + lI = O type

Q. If A = [[3, 1], [−1, 2]], show A² − 5A + 7I = O. Hence find A⁻¹.3 M · repeated

A² = [[9 − 1, 3 + 2], [−3 − 2, −1 + 4]] = [[8, 5], [−5, 3]].

A² − 5A + 7I = [[8 − 15 + 7, 5 − 5], [−5 + 5, 3 − 10 + 7]] = O ✓.

Multiply by A⁻¹: A − 5I + 7A⁻¹ = O ⇒ A⁻¹ = (5I − A)/7 = (1/7)[[2, −1], [1, 3]].

Same method: A = [[2, 3], [1, 3]] ⇒ A² − 5A + 3I = O ⇒ A⁻¹ = (5I − A)/3. (Always check the given equation numerically first.)

5. Solving a system using A⁻¹

Q. Solve x + y + 2z = 1, 3x + 2y + z = 7, 2x + y + 3z = 2 using the product of A = [[−5, 1, 3], [7, 1, −5], [1, −1, 1]] and B = [[1, 1, 2], [3, 2, 1], [2, 1, 3]].5 M · repeated

Step 1: AB = [[−5 + 3 + 6, −5 + 2 + 3, −10 + 1 + 9], [7 + 3 − 10, 7 + 2 − 5, 14 + 1 − 15], [1 − 3 + 2, 1 − 2 + 1, 2 − 1 + 3]] = [[4, 0, 0], [0, 4, 0], [0, 0, 4]] = 4I.

Step 2: AB = 4I ⇒ B⁻¹ = A/4.

Step 3: The system is BX = C with C = [1, 7, 2]ᵀ ⇒ X = B⁻¹C = (1/4)A C.

AC = [−5 + 7 + 6, 7 + 7 − 10, 1 − 7 + 2] = [8, 4, −4] ⇒ X = [2, 1, −1].

x = 2, y = 1, z = −1. ✓ (check: 2 + 1 − 2 = 1)

Pattern: the coefficient matrix of the system is one of the two given matrices (sometimes its transpose). Find the product, which is kI, so the other matrix divided by k is the inverse.

Q. Case study: bundles of pens, notebooks and erasers — write AX = B, find |A| and solve.4 M case

x + y + z = 40, 2x + y + 3z = 60, x + 2y + z = 65.

A = [[1, 1, 1], [2, 1, 3], [1, 2, 1]], |A| = 1(1 − 6) − 1(2 − 3) + 1(4 − 1) = −5 + 1 + 3 = −1 ≠ 0 ⇒ unique solution.

adj A = [[−5, 1, 2], [1, 0, −1], [3, −1, −1]] ⇒ A⁻¹ = −adj A.

X = A⁻¹B = −[−200 + 60 + 130, 40 + 0 − 65, 120 − 60 − 65] = −[−10, −25, −5] = [10, 25, 5]. Pen ₹10, notebook ₹25, eraser ₹5.

Steps to remember: |A| ≠ 0 → unique solution (consistent). |A| = 0 and (adj A)B ≠ O → inconsistent; |A| = 0 and (adj A)B = O → infinitely many or none (check further).

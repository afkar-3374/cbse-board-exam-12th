2. Techniques

Q. Partial fractions: ∫x/((x + 1)(x + 2)) dx and ∫x²/((x² + 1)(x² + 4)) dx.3–5 M · repeated

x/((x + 1)(x + 2)) = A/(x + 1) + B/(x + 2): A = −1, B = 2 → −log|x + 1| + 2 log|x + 2| + C.

Put x² = y: y/((y + 1)(y + 4)) = (−1/3)/(y + 1) + (4/3)/(y + 4) →

∫ = −(1/3) tan⁻¹x + (2/3) tan⁻¹(x/2) + C

2x/((x² + 1)(x² + 2)): put t = x² → ∫dt/((t + 1)(t + 2)) = log|(x² + 1)/(x² + 2)| + C.

A–R: partial fractions need deg P < deg Q; otherwise divide first.

Q. Integration by parts: ∫x²eˣ dx, ∫sin⁻¹x/x² dx.3 M

∫u v dx = u∫v dx − ∫[u′ ∫v dx] dx   (ILATE order for u)

∫x²eˣ dx = eˣ(x² − 2x + 2) + C.

∫sin⁻¹x · x⁻² dx = −sin⁻¹x/x + ∫dx/(x√(1 − x²)). The second integral (put x = sin θ, giving ∫cosec θ dθ) equals −log|(1 + √(1 − x²))/x|. Total: −sin⁻¹x/x − log|(1 + √(1 − x²))/x| + C.

3. Special forms (quadratic)

Q. ∫dx/√(5 − 8x − x²), ∫(3x + 1)/√(5 − 2x − x²) dx, ∫x²/(x² + 6x + 12) dx.3 M

Complete the square: 5 − 8x − x² = 21 − (x + 4)² ⇒ ∫ = sin⁻¹((x + 4)/√21) + C.

Linear over root: write 3x + 1 = A·d/dx(5 − 2x − x²) + B = A(−2 − 2x) + B ⇒ A = −3/2, B = −2. Then

∫ = −3√(5 − 2x − x²) − 2 sin⁻¹((x + 1)/√6) + C

Improper fraction: x²/(x² + 6x + 12) = 1 − (6x + 12)/(x² + 6x + 12) = 1 − 3(2x + 6)/(…) + 6/((x + 3)² + 3) ⇒ x − 3 log|x² + 6x + 12| + 2√3 tan⁻¹((x + 3)/√3) + C.

4. Definite integrals & properties

Q. List the properties of definite integrals.reference

P1: ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a − x)dx
P2: ∫₋ₐᵃ f = 2∫₀ᵃ f (f even), 0 (f odd)
P3: ∫₀^{2a} f = 2∫₀ᵃ f if f(2a − x) = f(x), else 0 if f(2a − x) = −f(x)

∫₀¹ dx/(1 + x²) = π/4. ∫ₑ^{e²} dx/(x log x) = [log log x] = log 2. ∫₋₂²(x⁵ + x³ + 1)dx = 0 + 4 = 4.

Q. Evaluate ∫₀^{π/4} log(1 + tan x) dx.5 M · repeated

I = ∫₀^{π/4} log(1 + tan x)dx. Using P1: tan(π/4 − x) = (1 − tan x)/(1 + tan x), so 1 + tan(π/4 − x) = 2/(1 + tan x).

I = ∫₀^{π/4} [log 2 − log(1 + tan x)]dx = (π/4) log 2 − I ⇒ I = (π/8) log 2.

∫₀^{π/2} log(tan x) dx: P1 gives I = ∫log(cot x) = −I ⇒ I = 0.

∫₀^{π/2} dx/(1 + √tan x) = π/4 (add I and its P1 form). ∫₀^{π/2} dx/(1 + tan x) = π/4.

∫₋₁²|x³ − x|dx: split at −1, 0, 1: ∫₋₁⁰(x³ − x) + ∫₀¹(x − x³) + ∫₁²(x³ − x) = ¼ + ¼ + 9/4 = 11/4.

∫₋ₐᵃ √((a − x)/(a + x)) dx = ∫(a − x)/√(a² − x²) = a·π − 0 = aπ (second part odd).

∫₀^{π/2} sin²x/(1 + sin x cos x) dx: add with cos²x version: 2I = ∫dx/(1 + sin x cos x) = ∫sec²x/(1 + tan x + tan²x) → 2I = 2π/(3√3) ⇒ I = π/(3√3).

5. Area under curves

Q. Find the area enclosed by y² = 4x and y = x.3–5 M · every paper

Intersection: x² = 4x ⇒ x = 0, 4.

A = ∫₀⁴ (2√x − x) dx = [(4/3)x^{3/2} − x²/2]₀⁴ = 32/3 − 8 = 8/3 sq units

y² = 2x and x − 2y = 0: intersect at y = 0, 4 (x = 8). A = ∫₀⁸(√(2x) − x/2)dx = (2√2/3)·8^{3/2} − 16 = 64/3 − 16 = 16/3.

y = √x, x = 4, x-axis: ∫₀⁴√x dx = 16/3.

Q. Circle and line: area in the first quadrant enclosed by x² + y² = 4, the line x = √3y and the x-axis (pizza case).4–5 M

Intersection: 3y² + y² = 4 ⇒ y = 1, x = √3.

A = ∫₀^{√3} (x/√3) dx + ∫_{√3}^{2} √(4 − x²) dx = √3/2 + [ (x/2)√(4 − x²) + 2 sin⁻¹(x/2) ]_{√3}^{2} = √3/2 + (π − √3/2 − 2π/3) = π/3 sq units (a 30° sector of radius 2 ✓).

Region {0 ≤ y ≤ √(4 − x²), x ≥ 2 − y}: quarter circle minus triangle = π − 2.

x² + y² = 8, y² = 2x, x-axis (first quadrant): meet at (2, 2). A = ∫₀²√(2x)dx + ∫₂^{2√2}√(8 − x²)dx = 8/3 + (2π − 2 − π) = π + 2/3.

Q. Area of a triangle with vertices A(−1, 1), B(1, 5), C(4, 2) using integration.5 M

AB: y = 2x + 3; BC: y = 6 − x; AC: y = (x + 6)/5.

A = ∫₋₁¹(2x + 3)dx + ∫₁⁴(6 − x)dx − ∫₋₁⁴ (x + 6)/5 dx = 6 + 10.5 − 7.5 = 9 sq units (check with the determinant formula: ½|−3 + 1 − 16| = 9 ✓).

Region under y = 2 + |x + 1| from −4 to 3: split at x = −1. ∫₋₄⁻¹(1 − x)dx = 10.5 and ∫₋₁³(x + 3)dx = 16 → 26.5 sq units.

6. Differential equations

Q. Order and degree.1 M · every paper

Order = highest derivative; degree = power of the highest derivative after making the equation polynomial in derivatives.

  • (y″)³ + (y′)⁵ + x³y = 0: order 2, degree 3.
  • d/dx[(dy/dx)⁴] = 0 ⇒ 4(y′)³y″ = 0: order 2, degree 1 ⇒ m + n = 3.
  • √(1 − y′) = y″ ⇒ 1 − y′ = (y″)²: order 2, degree 2.
  • y − x(y′)³ = a(y + y″)²: order 2, degree 2.
  • y‴ + sin(y′) = 0: degree not defined.

Q. Variable separable: dy/dx = 1 + x² + y² + x²y², y(1) = 0.3 M

dy/dx = (1 + x²)(1 + y²) ⇒ ∫dy/(1 + y²) = ∫(1 + x²)dx ⇒ tan⁻¹y = x + x³/3 + C. y(1) = 0 ⇒ C = −4/3 ⇒ tan⁻¹y = x + x³/3 − 4/3.

dy/dx = y tan x, y(0) = 1: log y = −log cos x + C ⇒ y = sec x. y dx − x dy = 0 ⇒ y = Cx.

Q. Homogeneous: x cos(y/x) dy/dx = y cos(y/x) + x; and 2xy dy/dx = x² + 3y².3–5 M

Put y = vx, dy/dx = v + x dv/dx.

(1) cos v (v + x v′) = v cos v + 1 ⇒ x cos v v′ = 1 ⇒ ∫cos v dv = ∫dx/x ⇒ sin(y/x) = log|x| + C.

(2) 2v(v + xv′) = 1 + 3v² ⇒ 2vx v′ = 1 + v² ⇒ ∫2v/(1 + v²) dv = ∫dx/x ⇒ log(1 + v²) = log|x| + C ⇒ x² + y² = Cx³.

(3) dy/dx − y/x + cosec(y/x) = 0, y(1) = 0: x v′ = −cosec v ⇒ −∫sin v dv = ∫dx/x ⇒ cos v = log|x| + C; y(1) = 0 ⇒ C = 1 ⇒ cos(y/x) = log|x| + 1.

Q. Linear DE: dy/dx + Py = Q. Solve dy/dx − y = cos x; (1 + x²)dy/dx + y = tan⁻¹x; dy/dx + y cot x = 2 cos x.3–5 M · very frequent

IF = e^{∫P dx},   y·IF = ∫Q·IF dx + C

(1) P = −1, IF = e⁻ˣ: y e⁻ˣ = ∫e⁻ˣ cos x dx = e⁻ˣ(sin x − cos x)/2 ⇒ y = (sin x − cos x)/2 + Ceˣ.

(2) P = 1/(1 + x²), IF = e^{tan⁻¹x}: y e^{tan⁻¹x} = ∫ tan⁻¹x e^{tan⁻¹x}/(1 + x²) dx = e^{tan⁻¹x}(tan⁻¹x − 1) + C ⇒ y = tan⁻¹x − 1 + Ce^{−tan⁻¹x}.

(3) IF = sin x: y sin x = ∫2 sin x cos x dx = sin²x + C; y(π/2) = 0 ⇒ C = −1 ⇒ y = sin x − cosec x.

cos x dy/dx + y = sin x: P = sec x, IF = sec x + tan x.

In x (dx/dy + Px = Q): (1 − y²)dx/dy + yx = ay ⇒ P = y/(1 − y²), IF = 1/√(1 − y²). y dx = (x + 2y²)dy ⇒ dx/dy − x/y = 2y, IF = 1/y ⇒ x/y = 2y + C ⇒ x = 2y² + Cy. (1 + y²)dx = (tan⁻¹y − x)dy ⇒ IF = e^{tan⁻¹y}.

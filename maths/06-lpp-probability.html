1. LPP: corner-point method

Q. Describe the steps to solve an LPP graphically.method

  1. Draw each constraint as a line (find intercepts); shade the side satisfying the inequality (test with (0, 0)).
  2. The common shaded region is the feasible region.
  3. Find the corner points (intersections).
  4. Evaluate Z at each corner; the largest/smallest value is the max/min (for a bounded region).
  5. If the region is unbounded, check the open half-plane (see §3).

An LPP optimises a linear objective function. If max occurs at two corners, every point on the segment joining them is optimal (infinitely many solutions).

3. Unbounded regions & special cases

Q. How do you decide the minimum for an unbounded feasible region?2–3 M

Let m be the smallest value of Z at the corners. Draw the open half-plane Z < m (e.g. 3x + 5y < m). If it has no point in common with the feasible region, m is the minimum; otherwise Z has no minimum. Same idea with Z > M for the maximum.

x ≥ 0, y ≥ 0, x + y ≥ 4: corner points (4, 0) and (0, 4) → 2 corner points; the region is unbounded.

Maximise Z = x + 2y, x + 2y ≥ 100, 2x − y ≤ 0, 2x + y ≤ 200: corners (0, 50), (20, 40), (50, 100), (0, 200) → Z = 100, 100, 250, 400 ⇒ max 400 at (0, 200).

Writing constraints from a graph: read each boundary line's intercepts, write its equation, decide ≤ or ≥ by testing the origin.

4. Probability: conditional, multiplication

Not in Pre-Board 1 — standard board-pattern questions.

Q. Define conditional probability and independent events.1–2 M

P(A|B) = P(A ∩ B)/P(B)  |  independent ⇔ P(A ∩ B) = P(A)P(B)
  • P(A) = 0.4, P(B) = 0.5, P(A ∩ B) = 0.2 → P(A|B) = 0.4 = P(A) → independent.
  • Independent events: P(A′ ∩ B′) = (1 − P(A))(1 − P(B)); P(A ∪ B) = 1 − P(A′)P(B′).
  • Two dice, sum 8 given first shows 3: only (3, 5) → 1/6.
  • Mutually exclusive events (with non-zero probabilities) are never independent.

5. Total probability & Bayes' theorem

Q. State Bayes' theorem. Bag I has 3 red, 4 black; bag II has 5 red, 6 black. A bag is chosen at random and a ball drawn is red. Find P(bag I).4–5 M

P(Eᵢ|A) = P(Eᵢ)P(A|Eᵢ) / Σ P(Eⱼ)P(A|Eⱼ)

P(I|R) = (½ · 3/7)/(½ · 3/7 + ½ · 5/11) = (3/7)/(3/7 + 5/11) = (33/77)/(68/77) = 33/68.

Other standard: a test 99% accurate for diseased, 0.5% false positive, 0.1% prevalence → P(disease | +) = 0.001×0.99/(0.001×0.99 + 0.999×0.005) ≈ 0.165.

6. Random variable & mean

Q. Find the probability distribution and mean of the number of heads in two tosses / number of aces in two draws.3 M

Σ P(xᵢ) = 1,   mean E(X) = Σ xᵢ P(xᵢ)

Two coins: X = 0, 1, 2 with P = ¼, ½, ¼ → E(X) = 1.

Two cards without replacement, X = number of aces: P(0) = (48/52)(47/51) = 188/221, P(1) = 2(4/52)(48/51) = 32/221, P(2) = (4/52)(3/51) = 1/221 → E(X) = 34/221 = 2/13.

Find k if P(X = x) = kx for x = 1, 2, 3, 4: k(1 + 2 + 3 + 4) = 1 ⇒ k = 1/10.

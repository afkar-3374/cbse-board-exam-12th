1-mark questions

Q1–18 are MCQs; Q19–20 are Assertion–Reason. A–R options: (a) both true, R explains A; (b) both true, R does not explain A; (c) A true, R false; (d) A false, R true.

1.If A is a square matrix of order 3 with |A| = 5, then |adj A| is

  1. 5
  2. 15
  3. 25
  4. 125
Show answer

(c) 25 — |adj A| = |A|ⁿ⁻¹.

2.R = {(1,1), (2,2), (3,3), (1,2)} on {1, 2, 3} is

  1. reflexive and symmetric
  2. reflexive and transitive but not symmetric
  3. an equivalence relation
  4. symmetric only
Show answer

(b) reflexive and transitive, not symmetric ((2,1) missing).

3.The principal value of cos⁻¹(−1/2) is

  1. −π/3
  2. π/3
  3. 2π/3
  4. 4π/3

(c) 2π/3

  1. 1
  2. −1
  3. 0

(c) 0 — for odd order, |A| = |A′| = |−A| = −|A|.

  1. 12

2-mark questions

Very short answer.

1.Show that R = {(a, b) : a ≤ b} on R is reflexive and transitive but not symmetric.

Show answer

a ≤ a (reflexive); a ≤ b, b ≤ c ⇒ a ≤ c (transitive); 1 ≤ 2 but 2 ≰ 1 (not symmetric).

2.Evaluate tan⁻¹(1) + cos⁻¹(−1/2) + sin⁻¹(−1/2).

Show answer

π/4 + 2π/3 − π/6 = 3π/4.

3.For what x is [[2, x], [4, 8]] singular?

Show answer

16 − 4x = 0 ⇒ x = 4.

4.Express A = [[1, 2], [3, 4]] as the sum of a symmetric and a skew-symmetric matrix.

Show answer

½(A + A′) = [[1, 2.5], [2.5, 4]]; ½(A − A′) = [[0, −0.5], [0.5, 0]].

5.Find k so that f(x) = (1 − cos 4x)/x² for x ≠ 0, f(0) = k, is continuous at 0.

Show answer

(1 − cos 4x)/x² = 2 sin²2x/x² → 2 × 4 = 8 ⇒ k = 8.

6.Differentiate y = xˣ.

Show answer

log y = x log x ⇒ dy/dx = xˣ(1 + log x).

7.Find dy/dx if x = a cos θ, y = a sin θ.

Show answer

dy/dx = (a cos θ)/(−a sin θ) = −cot θ.

8.Verify that y = e^{2x} satisfies y″ − 4y = 0.

Show answer

y′ = 2e^{2x}, y″ = 4e^{2x} ⇒ y″ − 4y = 0 ✓.

9.Find the interval in which f(x) = x² − 4x + 6 is strictly increasing.

Show answer

f′ = 2x − 4 > 0 ⇒ x > 2, i.e. (2, ∞).

10.The radius of a circle increases at 0.7 cm/s. How fast does its circumference increase?

Show answer

C = 2πr ⇒ dC/dt = 2π × 0.7 = 1.4π cm/s.

11.Find ∫ (x³ − 1)/x² dx.

Show answer

∫(x − x⁻²) dx = x²/2 + 1/x + C.

12.Evaluate ∫₀^{π/2} cos²x dx.

Show answer

∫(1 + cos 2x)/2 = [x/2 + sin 2x/4]₀^{π/2} = π/4.

13.Solve dy/dx = e^{x + y}.

Show answer

e^{−y} dy = eˣ dx ⇒ −e^{−y} = eˣ + C (or eˣ + e^{−y} = C).

14.Find the unit vector along a = 2i + 3j + 6k.

Show answer

|a| = 7 ⇒ (2i + 3j + 6k)/7.

15.|a| = 2, |b| = 3, a·b = 3. Find the angle between a and b.

Show answer

cos θ = 3/6 = ½ ⇒ θ = 60°.

16.Find the area of the parallelogram with adjacent sides i + j and j + k.

Show answer

(i + j) × (j + k) = i − j + k ⇒ area = √3.

17.Write the Cartesian and vector equations of the line through (1, 2, 3) parallel to 2i − j + 3k.

Show answer

(x − 1)/2 = (y − 2)/(−1) = (z − 3)/3; r = (i + 2j + 3k) + λ(2i − j + 3k).

18.Show that lines with direction ratios (2, −3, 4) and (1, 2, 1) are perpendicular.

Show answer

2 − 6 + 4 = 0 ⇒ perpendicular.

19.P(A) = 0.5, P(B) = 0.4, P(A ∩ B) = 0.2. Find P(A|B). Are A and B independent?

Show answer

P(A|B) = 0.2/0.4 = 0.5 = P(A) ⇒ independent.

20.P(X = x) = kx² for x = 1, 2, 3. Find k.

Show answer

k(1 + 4 + 9) = 1 ⇒ k = 1/14.

3-mark questions

Short answer.

1.Show that R = {(a, b) : 3 divides (a − b)} on Z is an equivalence relation and write the equivalence classes.

Show answer

a − a = 0 (reflexive); 3 | (a − b) ⇒ 3 | (b − a) (symmetric); a − c = (a − b) + (b − c) (transitive). Classes: [0], [1], [2] — integers leaving remainder 0, 1, 2 on division by 3.

2.Simplify tan⁻¹[cos x/(1 − sin x)], −π/2 < x < π/2.

Show answer

cos x/(1 − sin x) = (1 + tan(x/2))/(1 − tan(x/2)) = tan(π/4 + x/2) ⇒ π/4 + x/2.

3.Show that A = [[2, −1], [−1, 2]] satisfies A² − 4A + 3I = O. Hence find A⁻¹.

Show answer

A² = [[5, −4], [−4, 5]]; A² − 4A + 3I = O ✓. A⁻¹ = (4I − A)/3 = (1/3)[[2, 1], [1, 2]].

4.Find the area of the triangle with vertices (1, 0), (6, 0), (4, 3) using determinants.

Show answer

½|1(0 − 3) + 6(3 − 0) + 4(0 − 0)| = ½ × 15 = 7.5 sq units.

5.If y = (tan⁻¹x)², show that (1 + x²)²y″ + 2x(1 + x²)y′ = 2.

Show answer

(1 + x²)y′ = 2 tan⁻¹x. Differentiate: (1 + x²)y″ + 2xy′ = 2/(1 + x²). Multiply by (1 + x²) ✓.

6.Find dy/dx if xʸ = yˣ.

Show answer

y log x = x log y ⇒ y′ log x + y/x = log y + (x/y)y′ ⇒ y′ = (log y − y/x)/(log x − x/y).

7.Find the local maximum and minimum of f(x) = x³ − 6x² + 9x + 15.

Show answer

f′ = 3(x − 1)(x − 3). f″ = 6x − 12: f″(1) < 0 ⇒ local max f(1) = 19; f″(3) > 0 ⇒ local min f(3) = 15.

8.Find ∫ dx/(x² + 4x + 8).

Show answer

x² + 4x + 8 = (x + 2)² + 4 ⇒ ½ tan⁻¹((x + 2)/2) + C.

9.Find ∫ eˣ(1/x − 1/x²) dx.

Show answer

Form eˣ[f + f′] with f = 1/x ⇒ eˣ/x + C.

10.Evaluate ∫₀^π x sin x/(1 + cos²x) dx.

Show answer

Use P1: I = (π/2)∫₀^π sin x/(1 + cos²x) dx = (π/2)[−tan⁻¹(cos x)]₀^π = (π/2)(π/2) = π²/4.

11.Find the area enclosed between y = x² and y = x.

Show answer

Meet at 0, 1. ∫₀¹ (x − x²) dx = ½ − ⅓ = 1/6.

12.Solve x dy/dx = x + y.

Show answer

dy/dx − y/x = 1, IF = 1/x ⇒ y/x = log|x| + C ⇒ y = x log|x| + Cx.

13.Solve dy/dx + y/x = x².

Show answer

IF = x ⇒ xy = x⁴/4 + C ⇒ y = x³/4 + C/x.

14.a = 2i − j + k, b = i + j − 2k, c = i + 3j − k. Find λ such that a is perpendicular to λb + c.

Show answer

a·b = −1, a·c = −2 ⇒ −λ − 2 = 0 ⇒ λ = −2.

15.Find the shortest distance between r = (i + 2j + 3k) + λ(i − 3j + 2k) and r = (4i + 5j + 6k) + μ(2i + 3j + k).

Show answer

b₁ × b₂ = −9i + 3j + 9k, |·| = 3√19; (a₂ − a₁) = 3i + 3j + 3k ⇒ |−27 + 9 + 27|/3√19 = 3/√19.

16.Find the foot of the perpendicular from (1, 6, 3) to x/1 = (y − 1)/2 = (z − 2)/3 and the length.

Show answer

Point (λ, 2λ + 1, 3λ + 2); dot condition gives λ = 1 ⇒ foot (1, 3, 5), length √13.

17.Minimise Z = 200x + 500y subject to x + 2y ≥ 10, 3x + 4y ≤ 24, x, y ≥ 0.

Show answer

Corners (0, 5), (4, 3), (0, 6): Z = 2500, 2300, 3000 ⇒ min 2300 at (4, 3).

18.Machines A and B make 60% and 40% of items with 2% and 3% defective. An item is defective; find P(made by A).

Show answer

(0.6 × 0.02)/(0.6 × 0.02 + 0.4 × 0.03) = 0.012/0.024 = ½.

19.Two cards are drawn without replacement from a pack. Find the mean number of aces.

Show answer

P(0) = 188/221, P(1) = 32/221, P(2) = 1/221 ⇒ mean = 34/221 = 2/13.

20.Show that f(x) = |x − 1| + |x − 2| is continuous everywhere but not differentiable at x = 1 and x = 2.

Show answer

Sum of continuous functions is continuous. At x = 1: LHD = −2, RHD = 0; at x = 2: LHD = 0, RHD = 2 ⇒ not differentiable there.

4-mark case-based questions

Each has parts worth 1 + 1 + 2.

1.In a class, R = {(a, b) : a and b were born in the same month}. (i) Is R reflexive and symmetric? (ii) Is it transitive? (iii) How many equivalence classes can there be at most?

Show answer

(i) yes, yes (ii) yes, so R is an equivalence relation (iii) 12 (one per month).

2.f : R → R, f(x) = 3x + 2. (i) Is f one-one? (ii) Is f onto? (iii) Find f⁻¹ and f⁻¹(8).

Show answer

(i) yes (ii) yes, y = 3x + 2 ⇒ x = (y − 2)/3 ∈ R (iii) f⁻¹(x) = (x − 2)/3; f⁻¹(8) = 2.

3.A school awards prizes for honesty (x), regularity (y) and hard work (z): x + y + z = 6, y + 3z = 11, x + z = 2y. (i) Write AX = B. (ii) Find |A|. (iii) Solve.

Show answer

(i) A = [[1,1,1],[0,1,3],[1,−2,1]], B = [6, 11, 0] (ii) |A| = 1(1 + 6) − 1(0 − 3) + 1(0 − 1) = 9 (iii) x = 1, y = 2, z = 3.

4.Factory P makes 10 chairs and 5 tables daily, factory Q makes 8 chairs and 6 tables. A chair costs ₹500 and a table ₹1200 to make. (i) Write the production matrix. (ii) Write the cost matrix. (iii) Find daily cost at each factory.

Show answer

(i) [[10, 5], [8, 6]] (ii) [500, 1200]ᵀ (iii) P: 5000 + 6000 = ₹11,000; Q: 4000 + 7200 = ₹11,200.

5.A triangular plot has vertices A(1, 1), B(4, 1), C(4, 5). (i) Area by determinants? (ii) Equation of AC by determinants? (iii) Is (7, 9) on AC?

Show answer

(i) ½|1(1 − 5) + 4(5 − 1) + 4(1 − 1)| = 6 (ii) |x y 1; 1 1 1; 4 5 1| = 0 ⇒ 4x − 3y − 1 = 0 (iii) 28 − 27 − 1 = 0 ⇒ yes.

6.A taxi charges f(x) = 20 for 0 < x ≤ 2 km and 20 + k(x − 2) for x > 2 km. (i) Is f continuous at 2 for any k? (ii) Find f(5) if k = 12. (iii) Is f differentiable at 2 for k = 12?

Show answer

(i) yes, both sides give 20 (ii) 56 (iii) no — LHD = 0, RHD = 12.

7.A ball's height is h(t) = −5t² + 20t + 1 m. (i) Velocity at t = 1 s? (ii) When is it at the highest point? (iii) Maximum height (verify by second derivative)?

Show answer

(i) h′ = −10t + 20 = 10 m/s (ii) t = 2 s (iii) h″ = −10 < 0 ⇒ max h(2) = 21 m.

8.A spherical balloon's radius increases at 2 cm/s. (i) Write dV/dt. (ii) dV/dt when r = 5 cm? (iii) Rate of change of surface area at r = 5 cm?

Show answer

(i) 4πr² dr/dt (ii) 200π cm³/s (iii) dS/dt = 8πr dr/dt = 80π cm²/s.

9.A farmer has 120 m of fencing for a rectangular plot along a river (no fence on the river side). Width = x. (i) Area function? (ii) Critical point? (iii) Maximum area?

Show answer

(i) A = x(120 − 2x) (ii) A′ = 120 − 4x = 0 ⇒ x = 30 (iii) A″ = −4 < 0 ⇒ 1800 m².

10.An open box is made from an 18 cm square sheet by cutting squares of side x from the corners. (i) V(x)? (ii) Critical point? (iii) Maximum volume?

Show answer

(i) x(18 − 2x)² (ii) x = 3 (x = 9 rejected) (iii) V″(3) = −72 < 0 ⇒ 432 cm³.

11.A square-based tank with volume 1024 cm³: base and top cost ₹5/cm², sides ₹2.5/cm². (i) Height in terms of base x? (ii) Cost C(x)? (iii) Least cost?

Show answer

(i) h = 1024/x² (ii) C = 10x² + 10240/x (iii) C′ = 0 ⇒ x = 8, h = 16, C = ₹1920.

12.A particle's velocity is v(t) = 3t² + 2t m/s. (i) Acceleration at t = 1? (ii) Displacement from t = 0 to 2? (iii) Average velocity over [0, 2]?

Show answer

(i) 6t + 2 = 8 m/s² (ii) ∫₀²(3t² + 2t) dt = 8 + 4 = 12 m (iii) 6 m/s.

13.A parabolic arch is y = 4 − x² (metres). (i) Where does it meet the ground? (ii) Set up the area integral. (iii) Find the area under the arch.

Show answer

(i) x = ±2 (ii) 2∫₀²(4 − x²) dx (iii) 2(8 − 8/3) = 32/3 m².

14.A circular pizza x² + y² = 4 is cut along x = √3y. (i) Intersection in the first quadrant? (ii) Write the area integral between the cut, the x-axis and the crust. (iii) Find it.

Show answer

(i) (√3, 1) (ii) ∫₀^{√3}(x/√3)dx + ∫_{√3}^2 √(4 − x²) dx (iii) π/3.

15.A town's population grows at a rate proportional to itself and doubles in 10 years. (i) Write the DE. (ii) Solve it. (iii) When does it triple?

Show answer

(i) dP/dt = kP (ii) P = P₀e^{kt}, k = (ln 2)/10 (iii) t = 10 ln 3/ln 2 ≈ 15.8 years.

16.1% of people have a disease. A test detects it in 99% of patients but gives a false positive for 2% of healthy people. (i) P(positive)? (ii) P(disease | positive)? (iii) Comment.

Show answer

(i) 0.0099 + 0.0198 = 0.0297 (ii) 0.0099/0.0297 = 1/3 (iii) most positives are false because the disease is rare — confirm with a second test.

17.Two forces F₁ = 2i + 3j and F₂ = i − j + 2k act on a boat. (i) Resultant? (ii) Its magnitude? (iii) Angle between F₁ and F₂?

Show answer

(i) 3i + 2j + 2k (ii) √17 (iii) cos θ = (2 − 3)/(√13 · √6) = −1/√78.

18.Two drones fly along (x − 1)/2 = y/1 = (z − 2)/2 and (x − 2)/1 = (y − 4)/2 = (z − 2)/(−2) (km). (i) Angle between paths? (ii) Shortest distance? (iii) Is a 1.5 km safety gap kept?

Show answer

(i) 90° (ii) b₁ × b₂ = (−6, 6, 3), d = |(1, 4, 0)·(−6, 6, 3)|/9 = 2 km (iii) yes, 2 > 1.5.

19.A house at P(4, 2, 2) is to be joined to a pipeline (x − 1)/2 = (y + 1)/1 = (z − 2)/2 (1 unit = 10 m). (i) General point on the line? (ii) Foot of perpendicular? (iii) Length of pipe?

(i) (2λ + 1, λ − 1, 2λ + 2) (ii) λ = 1 ⇒ (3, 0, 4) (iii) 3 units = 30 m.

20.A carpenter makes tables (x) and chairs (y): x + y ≤ 40 (labour), 2x + y ≤ 60 (wood), profit Z = 50x + 30y. (i) Corner points? (ii) Optimal plan? (iii) Maximum profit?

Show answer

(i) (0,0), (30,0), (20,20), (0,40) (ii) 20 tables, 20 chairs (iii) ₹1600.

5-mark questions

Long answer. Key steps and results are given.

1.Show that R on N × N, (a, b) R (c, d) ⇔ ad = bc, is an equivalence relation.

Show answer

ab = ba (reflexive); ad = bc ⇒ cb = da (symmetric); ad = bc and cf = de ⇒ adcf = bcde ⇒ af = be (transitive, using c, d ≠ 0).

2.Show that f : R − {3} → R − {1}, f(x) = (x − 2)/(x − 3), is bijective and find f⁻¹.

Show answer

One-one: cross-multiplying gives x₁ = x₂. Onto: y = (x − 2)/(x − 3) ⇒ x = (3y − 2)/(y − 1) for y ≠ 1. f⁻¹(y) = (3y − 2)/(y − 1).

3.Solve 2x − 3y + 5z = 11, 3x + 2y − 4z = −5, x + y − 2z = −3 by the matrix method.

Show answer

|A| = −1 ≠ 0; X = A⁻¹B gives x = 1, y = 2, z = 3.

4.Find AB for A = [[1, −1, 0], [2, 3, 4], [0, 1, 2]] and B = [[2, 2, −4], [−4, 2, −4], [2, −1, 5]]. Use it to solve x − y = 3, 2x + 3y + 4z = 17, y + 2z = 7.

Show answer

AB = 6I ⇒ A⁻¹ = B/6. X = (1/6)B[3, 17, 7]ᵀ = (2, −1, 4).

5.Evaluate ∫₀^π x dx/(a²cos²x + b²sin²x).

Show answer

P1 ⇒ I = (π/2)∫₀^π dx/(…) = π∫₀^{π/2} sec²x dx/(a² + b²tan²x) = π²/2ab.

6.Find ∫ dx/((x + 1)(x² + 1)).

Show answer

1/((x + 1)(x² + 1)) = ½/(x + 1) + (−½x + ½)/(x² + 1) ⇒ ½ log|x + 1| − ¼ log(x² + 1) + ½ tan⁻¹x + C.

7.Evaluate ∫₀^{π/4} log(1 + tan x) dx.

Show answer

P1 gives 1 + tan(π/4 − x) = 2/(1 + tan x) ⇒ 2I = (π/4) log 2 ⇒ I = (π/8) log 2.

8.Find ∫ (x + 2)/√(x² + 2x + 3) dx.

Show answer

x + 2 = ½(2x + 2) + 1 ⇒ √(x² + 2x + 3) + log|x + 1 + √(x² + 2x + 3)| + C.

9.Find the area bounded by y² = 4x and x² = 4y.

Show answer

Meet at (0, 0), (4, 4). ∫₀⁴(2√x − x²/4) dx = 32/3 − 16/3 = 16/3.

10.Find the area of the ellipse x²/a² + y²/b² = 1 by integration.

Show answer

4 × (b/a)∫₀^a √(a² − x²) dx = 4 × (b/a)(πa²/4) = πab.

11.Find the area of {(x, y) : x² + y² ≤ 4, x + y ≥ 2}.

Show answer

Quarter circle minus triangle: π − 2.

12.Solve (1 + x²) dy/dx + 2xy = 1/(1 + x²), y(1) = 0.

Show answer

IF = 1 + x² ⇒ y(1 + x²) = tan⁻¹x + C; y(1) = 0 ⇒ C = −π/4 ⇒ y(1 + x²) = tan⁻¹x − π/4.

13.Solve x dy/dx − y + x sin(y/x) = 0.

Show answer

y = vx ⇒ x dv/dx = −sin v ⇒ ∫cosec v dv = −∫dx/x ⇒ x tan(y/2x) = C.

14.Show that the right circular cylinder of maximum volume inscribed in a sphere of radius R has height 2R/√3.

Show answer

r² = R² − h²/4; V = π(R²h − h³/4); V′ = 0 ⇒ h = 2R/√3; V″ < 0. Vmax = 4πR³/(3√3).

15.Show that the semi-vertical angle of the cone of maximum volume with given slant height l is tan⁻¹√2.

Show answer

r = l sin θ, h = l cos θ; V = (π/3)l³ sin²θ cos θ; dV/dθ = 0 ⇒ tan²θ = 2 ⇒ θ = tan⁻¹√2 (V″ < 0).

16.Find the line through (1, 2, −4) perpendicular to (x − 8)/3 = (y + 19)/(−16) = (z − 10)/7 and (x − 15)/3 = (y − 29)/8 = (z − 5)/(−5).

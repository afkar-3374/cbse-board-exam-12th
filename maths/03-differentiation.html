1. Continuity & differentiability

Q. When is f continuous at x = a? Find k so that f is continuous.1–3 M · 19 papers

limx→a⁻ f(x) = limx→a⁺ f(x) = f(a)
  • f = kx + 1 (x ≤ 5), 3x − 5 (x > 5): 5k + 1 = 10 ⇒ k = 9/5.
  • f = sin 5x/3x (x ≠ 0), k (x = 0): lim = 5/3 ⇒ k = 5/3.
  • f = k cos x/(π − 2x) (x ≠ π/2), 3 (x = π/2): limit = k/2 ⇒ k = 6.

Q. Show that f(x) = |x − 3| is continuous but not differentiable at x = 3. Is every differentiable function continuous?2–3 M · A–R

Continuity: LHL = RHL = f(3) = 0 ✓.

LHD = limh→0 [|−h| − 0]/(−h) = −1; RHD = lim [|h|]/h = 1 → LHD ≠ RHD → not differentiable (sharp corner).

Differentiability ⇒ continuity, but not conversely.

f = 2x + 3 (x ≤ 4), x² − 5 (x > 4): both give 11 at 4 (continuous); LHD = 2, RHD = 8 → not differentiable.

Q. Logarithmic differentiation: differentiate x^{sin x}, (cos x)^x + x^{sin x}, xˣ, 5ˣ/x⁵.3 M · very frequent

y = x^{sin x} ⇒ log y = sin x log x ⇒ (1/y)y′ = cos x log x + sin x/x ⇒

dy/dx = x^{sin x}[cos x log x + (sin x)/x]

For a sum like (cos x)ˣ + x^{sin x}: put u = (cos x)ˣ, v = x^{sin x}, differentiate each separately, add.

u = (cos x)ˣ: u′ = (cos x)ˣ[log cos x − x tan x].

xʸ = e^{x−y}: take logs: y log x = x − y ⇒ y = x/(1 + log x) ⇒ dy/dx = log x/(1 + log x)² (quotient rule).

Q. Parametric and implicit differentiation.2 M

  • x = at², y = 2at: dy/dx = 2a/(2at) = 1/t.
  • x = sin³t, y = cos³t: dy/dx = (−3cos²t sin t)/(3 sin²t cos t) = −cot t.
  • x = a sec t, y = b tan t: dy/dx = b sec²t/(a sec t tan t) = (b/a) cosec t; at t = π/6: 2b/a.
  • cos y = x cos(a + y): x = cos y/cos(a + y) ⇒ dx/dy = sin a/cos²(a + y) ⇒ dy/dx = cos²(a + y)/sin a.
  • y = sin(x + y) with dy/dx = 0: y′ = cos(x + y)/(1 − cos(x + y)) = 0 ⇒ cos(x + y) = 0 ⇒ y = sin(x + y) = ±1.

3. Second-order derivatives (prove-that)

Q. If y = sin⁻¹x, prove (1 − x²)y″ − xy′ = 0.2–3 M · repeated

y′ = 1/√(1 − x²) ⇒ √(1 − x²) y′ = 1. Square: (1 − x²)y′² = 1. Differentiate: (1 − x²)·2y′y″ − 2x y′² = 0. Divide by 2y′: (1 − x²)y″ − xy′ = 0.

y = e^{a sin⁻¹x}: same trick gives (1 − x²)y″ − xy′ − a²y = 0.

y = 5 cos x − 3 sin x: y″ = −5 cos x + 3 sin x = −y ⇒ y″ + y = 0.

y = log(x²/e²) = 2 log x − 2 ⇒ y″ = −2/x².

Method: get rid of roots/inverse functions first (cross-multiply, square), then differentiate again.

4. Rate of change

Q. Sand is poured at 12 cm³/s into a conical heap with height = radius. Find dh/dt when h = 4 cm.3 M

V = ⅓πr²h = ⅓πh³ ⇒ dV/dt = πh² dh/dt ⇒ 12 = π(16) dh/dt ⇒ dh/dt = 3/(4π) cm/s.

Area of circle: dA/dr = 2πr = 10π at r = 5. Cube edge growing at 3 cm/s: dV/dt = 3x² · 3 = 900 cm³/s at x = 10.

Ball of diameter (3x + 1): V = (π/6)(3x + 1)³ ⇒ dV/dx = (π/6)·3(3x + 1)²·3 = (3π/2)(3x + 1)² = 24π at x = 1.

5. Increasing / decreasing

Q. Find the intervals where f(x) = 2x³ − 9x² + 12x + 15 is increasing or decreasing.2–3 M

f′(x) = 6x² − 18x + 12 = 6(x − 1)(x − 2).

Increasing on (−∞, 1] ∪ [2, ∞); decreasing on [1, 2].

P(x) = x³ − 6x² + 9x + 20: P′ = 3(x − 1)(x − 3) → decreasing on (1, 3).

f(x) = sin x + cos x on [0, 2π]: f′ = cos x − sin x > 0 on [0, π/4) ∪ (5π/4, 2π] (increasing), decreasing on (π/4, 5π/4).

4x³ − 18x² + 27x − 7: f′ = 3(2x − 3)² ≥ 0 → always increasing.

x² + ax + 1 strictly increasing on (1, 2): 2x + a > 0 for x > 1 ⇒ a ≥ −2, least a = −2.

√3 sin x − cos x − 2ax + 6 decreasing on R: f′ = √3 cos x + sin x − 2a = 2 sin(x + π/3) − 2a ≤ 0 for all x ⇒ 2 − 2a ≤ 0 ⇒ a ≥ 1.

6. Maxima & minima

Q. State the first and second derivative tests.method

  1. Find critical points: f′(c) = 0.
  2. First derivative test: f′ changes + → − at c: local max; − → +: local min.
  3. Second derivative test: f″(c) < 0: max; f″(c) > 0: min; f″(c) = 0: test fails.
  4. Absolute max/min on [a, b]: compare f at critical points and at the end points.

Absolute: f(x) = 4x − x²/2 on [−2, 9/2]: f′ = 4 − x = 0 at 4; f(−2) = −10, f(4) = 8, f(4.5) = 7.875 → max 8, min −10.

f(x) = cos x + sin²x on [0, π]: f′ = −sin x + 2 sin x cos x = sin x(2cos x − 1) = 0 at 0, π/3, π. f(0) = 1, f(π/3) = 1/2 + 3/4 = 5/4, f(π) = −1 → absolute max 5/4.

Q. Open box from a square sheet of side 18 cm by cutting equal squares of side x from each corner. Find x for maximum volume.4–5 M · case study

V = x(18 − 2x)², 0 < x < 9.

V′ = (18 − 2x)² − 4x(18 − 2x) = (18 − 2x)(18 − 6x) = 0 ⇒ x = 3 (x = 9 gives no box).

V″ = 24x − 144 ⇒ V″(3) = −72 < 0 ⇒ maximum. x = 3 cm, Vmax = 3 × 12² = 432 cm³.

Q. Other repeated max–min problems.4–5 M

  • Fence along a river (120 m, river side free): A = x(120 − 2x), A′ = 120 − 4x = 0 ⇒ x = 30, Amax = 1800 m².
  • Square-base box, volume 1024 cm³, top/bottom ₹5/cm², sides ₹2.5/cm²: h = 1024/x², C = 10x² + 2.5 × 4x × 1024/x² = 10x² + 10240/x. C′ = 20x − 10240/x² = 0 ⇒ x³ = 512 ⇒ x = 8, h = 16, Cmin = 640 + 1280 = ₹1920.
  • Helicopter on y = x² + 7, soldier at (3, 7): D² = (a − 3)² + a⁴. d/da = 2(a − 3) + 4a³ = 0 ⇒ 2a³ + a − 3 = 0 ⇒ a = 1 → nearest point (1, 8), distance √5.
  • Profit P(x) = −3x² + 240x − 1200: P′ = 0 at x = 40, P″ = −6 < 0, Pmax = −4800 + 9600 − 1200 = 3600 (thousand). At x = 30: 3300, short by 300. At x = 50: 3300 (diminishing returns).
  • Right triangle with given hypotenuse + side sum, rectangle in a circle, etc. — always write one variable, differentiate, test.
